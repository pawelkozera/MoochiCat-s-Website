# Project conventions

- Write all code, comments, and user-facing text in English.
- Use React, TypeScript, Vite, and Supabase.
- Do not read, modify, or print .env files or .env.* files.
- You may read and update .env.example using placeholders only.
- Do not inspect environment variable values or print credentials.
- Ask the user to configure credentials manually when needed.
- Never put server-side secrets in frontend code or VITE_ variables.
